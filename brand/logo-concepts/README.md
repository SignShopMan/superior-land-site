# Heritage shield: logo concepts

Rough direction sketches, not production art. The text is live Barlow Condensed (not outlined),
the trees are placeholder triangles, and the shield curve needs a designer's hand.

Colors: charcoal `#1E2326`, Superior orange `#E5641E`, bone `#F4F2EE`.

| File | Role |
|---|---|
| `c3-full-badge.svg` | **Primary.** Truck doors, job-site signs, social avatar. Use only at 64px and up. |
| `c2-treeline-mark.svg` | **Compact mark.** Hard hats, embroidery, favicon, equipment decals, anything under 64px. |
| `lockup-horizontal.svg` | Website header, letterhead, bid covers, email signature. |
| `c1-monogram.svg` | Alternate compact mark (S monogram). |
| `c4-monoline.svg` | Most refined alternate, furthest from the original. |

| `c7-lockup-horizontal.svg` | Website header, letterhead, bid covers: the cluster bookends the grade line. |
| `vignette-trees-blades.svg` | The signature cluster on its own. Always small, never the hero. |

| `c6-grass-lockup.svg` | Cleaned-up evolution of his current lockup (blades + SUPERIOR + ground line). For the website header, letterhead and bid covers. |
| `c5-breakout-shield.svg` | Earlier favorite. Trees break out of a double-keyline shield, with a wide SUPERIOR across it. Structure borrowed from a stock template the client liked, so it must not copy that template's mountain, shape or type. |
| `c5-breakout-compact.svg` | Compact mark for c5: trees kept inside the shield, grade line below. |

Designer brief: keep the 1997 shield silhouette and the orange. Drop chrome, gradients, glow and
the phone number. Custom-draw the SUPERIOR lettering and the treeline. Deliver 1-color, reversed
and full-color versions, all as outlined SVG/EPS, plus a stitch-ready file for embroidery.

**Trademark note:** the current logo uses the Bobcat cat head and the John Deere deer, and the old company name includes "Bobcat." These are registered trademarks. None of them may appear in the new identity.
